# Recipe Finder

A simple web app that lets you search for recipes by meal name or ingredient.  
It uses the free [TheMealDB](https://www.themealdb.com/) API to display:

- Meal name  
- Meal image  
- Link to a recipe page or video  
- Full cooking instructions

---

## Features
- Search for any dish (e.g. *chicken*, *pasta*).
- Displays multiple results if more than one meal matches.
- Clickable link to the official recipe or YouTube video.

---

## Tech Stack
- **HTML** for structure  
- **CSS** for styling  
- **JavaScript (ES6)** for fetching API data and DOM manipulation  
- **TheMealDB API** as the data source

---

## How to Run
1. Clone or download this repository.  
2. Open `index.html` in your browser.  
3. Type an ingredient or meal name and press **Search**.

No build tools or server required.
